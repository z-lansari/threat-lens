# ThreatLens

**Independent Threat Intelligence Platform**

ThreatLens is a standalone threat intelligence platform that allows users and
external systems (SIEM, SOAR, security tools) to analyze indicators of
compromise (IOCs) such as IPs, domains, URLs, and file hashes.

## Features

- IOC analysis (IP, Domain, URL, File Hash)
- Threat scoring engine
- REST API for integration with external systems
- Web dashboard for human users
